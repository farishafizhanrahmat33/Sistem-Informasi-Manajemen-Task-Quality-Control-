FAQ & Full System Guide

Docs and Q&A covering all the features available in the QA Control Center.

You can sign in with your registered Username or Email plus your password through the Sign In button in the navbar/sidebar. Once you're in, head to Profile Settings to update your full name, email, change your profile picture, and change your password whenever you want.

The Dashboard shows a real-time summary straight from the database, broken down by these quality categories:
  • Need Sample: New tasks that still need a test sample.
  • Sample Done: Tasks whose sample work is already finished.
  • Revision: Tasks that need fixes or another pass.
  • Ready: Tasks that got approved (Passed) and are good to go for production.
  • Skipped: Tasks marked to be skipped this round.

From the Task Management menu, users with Developer or Quality Control access can upload project data files in Excel (.xlsx, .xls) or CSV format. The system will auto-sync the task data into the database. You can also filter data, search by keyword, update task status/notes, forward tasks to the production team, or permanently delete a whole project.

The QR Management menu is where Developers and Quality Control folks upload reference documents in PDF format. Users can open those docs right in a clean pop-up (Modal) viewer with no extra toolbar clutter, which makes it way easier to review stuff out in the field.

The system runs on Role-Based Access Control:
  • Developer: Top-level access — covers user management, system settings, support tickets, plus full control over tasks and documents.
  • Quality Control: Full access to import project data, evaluate tasks, change QC status, and manage PDF documents.
  • Supervisor: Can view the dashboard, filter tasks, and forward tasks to the production team.
  • Public (Guest): Regular visitors who can only see the dashboard summary and the list of tasks already sent to production.

Head over to the Customer Service menu to send in a message about any issue or bug straight to the engineering team. If you're a Developer, you can check every incoming message through the dedicated Support Tickets menu.

Use the Search box to find tasks by ID, name, or description instantly. For more sorting options, hit the Sort Data button (top right corner) to filter by a specific Project or Package. If nothing shows up, double-check that a filter isn't already active.

We've got a Real-time Auto-Update feature built in. The app checks the database for changes every 5 seconds. That way, any status change made by the QC team shows up instantly for Leaders and other users without anyone needing to manually refresh the page.
